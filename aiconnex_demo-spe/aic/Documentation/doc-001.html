2. Functional Design & Overview

AI-CONNEXX is a Total Automation Solution (TAS) machine learning workflow studio designed for industrial diagnostics, prognostics, and real-time sensor telemetries. At its core, the platform allows industrial engineers—who might not be professional data scientists—to upload multi-table archives and build robust regression or classification prediction services automatically.

By connecting ingestion modules, data profiling nodes, feature engineers, splitters, estimators, validation gateways, and monitoring APIs, the studio builds a seamless pipeline. It translates complex machine learning operations into intuitive, visual drag-and-drop actions.
