SPLIT, TRAIN & EVALUATE

Document Summary

Splitting logic, fitting models, and generating regression/classification scorecards.

1. Data Flow Chart

2. Functional Design & Overview

These three backend services run consecutively:

  • Split: Splits data into train and test segments. For temporal datasets, standard random splitting can leak information. The partitioner therefore supports sequential splitting to preserve temporal order.
  • Train: Fits regression (e.g. Ridge Regression, Random Forests) or classification models in independent tasks to avoid main thread timeouts.
  • Evaluate: Generates error scorecards (RMSE, MAE, R2 scores for regression, or Accuracy, Precision, Recall, F1 for classification).

3. Implementation Code Reference

# Sequential split for time series data def split_sequential(df, test_size=0.2): split_idx = int(len(df) * (1 - test_size)) train = df.iloc[:split_idx] test = df.iloc[split_idx:] return train, test
