Recipe Structure

outlier_methodiqr | z-score | none

                            
scale_methodstandard | min-max | none

                            
encode_strategyone-hot | label | none

                            
text_cleanlowercase | strip | regex | none

                            
time_alignresample_freq | lag_features | none

💧
Impute
Missing value imputation strategies applied per column during the prepare step.
Strategies
mean
Replace missing numeric values with the column mean. Best for normally distributed data.
median
Replace with median. Robust to outliers — recommended for skewed distributions.
mode
Replace categorical missing values with the most frequent category.
zero
Fill all missing values with 0. Used for sparse or count-based features.
Prepare API Payload Key
"impute_strategy": "mean" | "median" | "zero"


                
📉
Outlier Handling
Detect and clip extreme values in numeric columns before model training.
Methods
IQR
Inter-Quartile Range: clips values outside [Q1 − 1.5×IQR, Q3 + 1.5×IQR]. Standard robust method.
Z-Score
Clips values beyond ±3 standard deviations from the mean. Best for near-normal distributions.
none
No outlier treatment applied. Use for tree-based models which are naturally robust to outliers.
Prepare API Payload Key
"outlier_method": "iqr" | "z-score" | "none"


                
🔡
Encode
Convert categorical features into numerical representations suitable for ML algorithms.
Strategies
one-hot
Creates a binary column for each category value. Ideal for nominal (unordered) categories. Increases dimensionality.
label
Assigns an integer ID per unique category. Compact representation, suitable for tree-based models.
none
No encoding applied. Use when categorical columns are already numeric or pipeline handles it separately.
Prepare API Payload Key
"encode_strategy": "one-hot" | "label" | "none"


                
📐
Scale
Normalize numeric feature ranges for distance-based and gradient-based algorithms.
Methods
standard
Standardize to zero mean and unit variance (z-score normalization). Best for SVM, Neural Networks, Logistic Regression.
min-max
Scales values to [0, 1] range. Useful when bounded range is required (e.g. neural network inputs).
none
No scaling. Use for tree-based algorithms (Random Forest, XGBoost) which are scale-invariant.
Prepare API Payload Key
"scale_method": "standard" | "min-max" | "none"


                
📝
Text Clean
Preprocessing pipeline for text columns including normalization, tokenization, and noise removal.
Operations
lowercase
Convert all text to lowercase for case-insensitive matching.
strip
Remove leading/trailing whitespace and normalize internal spaces.
regex
Apply custom regex patterns to remove special characters, HTML tags, or URLs.
stopwords
Remove common stop words (the, is, at, etc.) for NLP feature extraction tasks.
Prepare API Payload Key
"text_clean": ["lowercase", "strip", "regex"]


                
⏱️
Time Align
Temporal alignment and feature engineering for time-series datasets.
Operations
resample
Aggregate/interpolate time-series data to a uniform frequency (daily, hourly, etc.).
lag_features
Create lagged versions of columns (t-1, t-2, ...) as additional features for sequence prediction.
rolling_stats
Compute rolling window mean, std, min, max to capture temporal trends.
cycle_encode
Encode cyclic temporal features (hour-of-day, day-of-week) using sin/cos transforms.
Prepare API Payload Key
"time_align": { "resample_freq": "1D", "lag_n": 3 }

✖️
Polynomial & Interaction Features
Generates quadratic terms and feature interactions for continuous numeric variables.
Settings
polynomial_degree
Degree 2 generates square terms (x^2) and pairwise cross-terms (x1 * x2).
interaction_features
When true, only cross-product interaction terms are generated without pure square powers.


                
📊
PCA & Dimensionality Reduction
Linear orthogonal transformation into principal components capturing maximum variance.
Settings
pca_components
Number of orthogonal principal components (pca_1, pca_2, ...) to compute and append.


                
🎯
Feature Selection
Statistical feature filtering using ANOVA F-test / Mutual Information to eliminate uninformative features.
Settings
k_best_features
Select top K informative numeric features based on target correlation/score.


                
🧮
Row Aggregations
Generates row-wise statistical aggregates across all numerical columns.
Generated Features
feat_row_mean
Average value across numeric features per row
feat_row_std
Standard deviation across numeric features per row
feat_row_sum
Total sum across numeric features per row

🔍
Algo Fetch
Reads the training recipe to determine which algorithm and variant to instantiate.
Supported Algorithms
Logistic RegressionL1, L2, ElasticNet, Balanced
Linear RegressionStandard, Huber
Ridge / LassoAlpha-regularized linear models
Random ForestClassifier & Regressor, Balanced
XGBoostClassifier & Regressor (sklearn fallback)
LightGBMClassifier & Regressor (sklearn fallback)
Isolation ForestAnomaly detection
K-MeansClustering, configurable k
Linear (ARIMA proxy)Time-series trend fitting


                
⚙️
Hyper Tuning
Configure hyperparameters for the selected algorithm via the training recipe JSON.
Hyperparameter Fields
n_estimatorsNumber of trees (default: 100)
max_depthTree depth limit (null = unlimited)
learning_rateBoosting step size (default: 0.1)
l1_ratioElasticNet mixing (0=L2, 1=L1)
alphaRegularization strength for Ridge/Lasso
n_clustersK-Means cluster count (default: 3)
contaminationIsolation Forest anomaly fraction ("auto")


                
🏆
Final Model Train
Trains the fully configured model on the train partition and serializes it as a pickle file.
Training Process
1. Load
Load train_{run_id}.csv from workspace_data. Separate X and y by target column.
2. Fill NaN
Apply median imputation to any remaining NaN values in X_train.
3. Fit
Instantiate and fit the algorithm with the configured hyperparameters.
4. Serialize
Pickle the fitted model to workspace_data/model_{run_id}.pkl.
Output
workspace_data/model_{run_id}.pkl
