VALIDATION GATEWAY 1 (VG-1)

Document Summary

Ensures metric quality satisfies accuracy thresholds.

1. Data Flow Chart

2. Functional Design & Overview

Validation Gateway 1 (VG-1), located in aiconnex_ml.shared.data.validation_gate_1, is a pre-training quality check. It audits training sets before training begins to avoid compute waste or silent failures:

  • Zero Variance Check: Scans numeric columns and rejects datasets if any features have constant values.
  • Target Leakage Check: Identifies columns with abnormally high correlations to the target, warning the user of potential leakage.
  • Missing Value Check: Aborts execution if the target column contains null values or if features exceed a 50% missing value threshold.
  • Imbalance Check: For classification tasks, warns if class proportions exceed 1:1000.

3. Implementation Code Reference

# VG_1 pre-training data quality checks in validation_gate_1.py import pandas as pd from typing import Tuple def check_vg1(manifest: dict, df_train: pd.DataFrame) -> Tuple[bool, dict]: """Performs structural and statistical verification of training data.""" report = {"gate": "VG_1", "passed": True, "checks": {}} # 1. Zero Variance check numeric_df = df_train.select_dtypes(include='number') zero_var_cols = [c for c in numeric_df.columns if df_train[c].var() == 0] report["checks"]["zero_variance"] = { "passed": len(zero_var_cols) == 0, "detail": f"Constant columns detected: {zero_var_cols}" } # 2. Target Missing values check target_col = manifest.get("label_contract", {}).get("target_column") if target_col and target_col in df_train.columns: null_ratio = df_train[target_col].isnull().mean() report["checks"]["target_nulls"] = { "passed": null_ratio < 0.05, "detail": f"Missing values in target: {null_ratio:.2%}" } report["passed"] = all(c["passed"] for c in report["checks"].values()) return report["passed"], report
